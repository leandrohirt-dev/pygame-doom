# Doom em Pygame

Versão simplificada inspirada em Doom, criada em Python e Pygame como
mostrado no vídeo. O efeito 3D usa raycasting: raios medem a distância até
as paredes e viram colunas na tela.

## Como executar

Tenha o Python instalado. Na pasta do repositório, execute:

```bash
python -m pip install -r requirements.txt
python doom.py
```

No Windows, se o comando `python` não funcionar, use `py` no lugar dele.

Use as **setas para cima e para baixo** para andar, as **setas esquerda e
direita** para girar e **espaço** para atirar. Feche a janela para sair.

## Código passo a passo

O arquivo `doom.py` contém o jogo completo. A pasta `passos/` mostra as
quatro versões executáveis apresentadas no vídeo: raios, efeito 3D,
demônios e arma.
